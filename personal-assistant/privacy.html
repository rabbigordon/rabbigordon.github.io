Privacy policy – Claude Gmail Reader

Last updated: November 3, 2026 (access widened)

Claude Gmail Reader is a personal tool operated by Mendel Gordon on his own computer. Only its operator signs in to it.

What data it accesses

With the operator's permission, the tool reads the operator's Gmail messages (read-only), and reads and edits the operator's Google Drive files, Docs, Sheets, Slides, Forms, Calendar, Contacts, Tasks and Google Apps Script projects. It does not send email.

How the data is used

The data is used only to carry out the operator's own instructions. It is not sold, not used for advertising, and not shared with anyone else.

Storage and security

Sign-in tokens are stored only on the operator's own computer, in files readable only by the operator's user account. Data is fetched when needed and is not kept in a separate database.

Google API Services User Data Policy

Claude Gmail Reader's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
