Privacy policy – ChabadOne Ads Assistant

Last updated: October 29, 2026

ChabadOne Ads Assistant is an internal tool operated by Mendel Gordon (ChabadOne, Chabad.org) to manage the Google Ads accounts in the ChabadOne Sites manager account. Only its operator signs in to it.

What data it accesses

With the operator's permission (the Google Ads OAuth scope), the tool reads Google Ads account data: account and campaign settings, ads, keywords, policy status and performance reports. It changes that data only when the operator approves a specific change. It does not access any other Google data.

How the data is used

The data is used only to report on and manage those Google Ads accounts. It is not sold, not used for advertising, and not shared with anyone except as needed to carry out the operator's own instructions.

Storage and security

Sign-in tokens are stored only on the operator's own computers, in files readable only by the operator's user account. Account data is fetched when needed and is not kept in a separate database.

Google API Services User Data Policy

ChabadOne Ads Assistant's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
